# Changelog

All notable public changes to ComfyUI Media Utility will be documented here.

## [1.0.0] - 2026-08-14

First public release.

### Extract / Trim
- Video and audio loading with drag/drop support.
- Full-resolution PNG frame extraction.
- Video viewer zoom and pan.
- In/Out selection and selection playback.
- Full timeline plus precision zoomed timeline.
- High-contrast zoom-window overview.
- Fixed zoom-window scrubbing.
- Center on Playhead and Playhead → Left controls.
- WAV extraction / audio trimming.
- Fast MP4 stream-copy cuts.
- Exact H.264/AAC MP4 cuts.
- Local output-folder support.

### Sort
- Image, video, and audio sorting.
- Move / Copy workflows.
- Destination hotkeys.
- Skip / Back / Trash / Undo.
- Media filters and autoplay preview.

### Compare
- Image, video, and audio comparison.
- Tournament and Browse modes.
- Image/video/audio Reference support.
- Adjustable Reference size.
- Hover Audio and Select Audio modes.
- Shortlist / finalist / winner workflows.
- Winner/shortlist copy or move.
- View Sync scopes: Left + Right, All 3, None.
- Independent Zoom and Pan synchronization.
- Reset View.
- New Compare reset workflow.

### Packaging
- Local-only Python launcher.
- No pip dependencies.
- First-run local FFmpeg dependency cache.
- Public repository documentation and licensing files.
