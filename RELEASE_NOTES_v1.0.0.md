# ComfyUI Media Utility v1.0.0

First public release of **ComfyUI Media Utility** — a lightweight local media companion designed for quick ComfyUI-adjacent media work without opening a full editing application.

## Three workspaces

**Extract / Trim**
- PNG frame grabs at native source resolution
- Video/audio In & Out points
- Precision zoomed timeline
- MP4 Fast Cut / Exact Cut
- WAV extraction and trimming
- Viewer zoom and pan

**Sort**
- Quickly move/copy images, video, and audio into category folders
- Hotkeys, Trash, Undo, Skip, and autoplay preview

**Compare**
- Side-by-side image/video/audio comparison
- Tournament and Browse modes
- Optional Reference image/video/audio
- Shortlist / finalist workflow
- Flexible zoom/pan synchronization
- Hover Audio / Select Audio auditioning

## Requirements

- Windows 10/11
- Python 3
- Chrome or Edge recommended

No pip packages or ComfyUI custom nodes are required.

## First launch

Unzip the release and run:

`Launch_ComfyUI_Media_Utility.bat`

The first launch downloads and caches the pinned FFmpeg browser engine (~32 MB) for MP4/WAV export. Media processing remains local on your machine.

See `README.md` for full instructions and limitations.
