COMFYUI MEDIA UTILITY v1.0.0
============================

QUICK START
-----------
1. Keep this entire folder together.
2. Double-click Launch_ComfyUI_Media_Utility.bat
3. Leave the command window open while using the app.
4. The app opens in your browser automatically.

REQUIREMENTS
------------
- Windows 10/11
- Python 3
- Chrome or Edge recommended
- Internet connection on first launch for the FFmpeg export engine

No pip packages or ComfyUI custom nodes are required.

FIRST LAUNCH
------------
The launcher downloads about 32 MB of pinned FFmpeg browser files for MP4/WAV
export and caches them under vendor/ffmpeg/.

If that setup fails, Sort, Compare, playback, and PNG frame capture still work.
Run Setup_FFmpeg_Engine.bat later to retry/repair export support.

PRIVACY
-------
The app runs at 127.0.0.1 on your own computer.
Your images, video, and audio are not uploaded.

See README.md for the full user guide.
