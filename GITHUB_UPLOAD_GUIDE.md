# GitHub Upload Guide

## Main repository

Create a repository named something like:

`ComfyUI-Media-Utility`

Upload the **contents** of the GitHub Source ZIP to the repository root.

Recommended description:

> Lightweight local media companion for ComfyUI — extract/trim, sort, and compare image, video, and audio without opening a full editor.

Suggested topics:

`comfyui` `media` `video` `audio` `image` `ffmpeg` `workflow` `utility` `local`

## First public release

1. Create a GitHub Release.
2. Tag: `v1.0.0`
3. Title: `ComfyUI Media Utility v1.0.0`
4. Copy the text from `RELEASE_NOTES_v1.0.0.md`.
5. Attach:

   `ComfyUI-Media-Utility-v1.0.0-Windows.zip`

The repository source ZIP generated for you is for convenient uploading/backups.
GitHub itself will also generate Source code ZIP/TAR archives automatically once tagged.
